# 15. 상태 파일 안전하게 쓰기, 목록에 없는 언론사 (2026-11-13)

## 한 줄 요약

상태 파일은 **임시 파일에 다 쓴 뒤 이름만 바꿔** 쓴다(원자적 쓰기). 그리고 방침을 아직 안 적은 언론사는 **피드 목록까지 보고** "제목만"으로 잡는다.

## 왜 필요한가

**원자적 쓰기**: 차단기·언론사 방침은 `logs/*.json` 파일에 저장된다. 예전에는 파일에 바로 썼다. 쓰는 도중에 프로그램이 죽으면 파일이 반만 남는다. 다음 실행에서 이 파일을 읽으면 깨진 JSON 이라 빈 값 `{}` 으로 읽힌다. 그러면 자동으로 걸어 둔 "제목만" 전환이 조용히 풀린다.
공책에 고쳐 쓰다가 찢어지면 원래 내용도 날아간다. 새 종이에 다 쓴 뒤 바꿔 끼우면, 중간에 멈춰도 원래 종이는 그대로 남는다.

**목록에 없는 언론사**: `press_policy.py` 설명에는 "목록에 없는 언론사는 TITLE_ONLY" 라고 적혀 있었다. 그런데 `title_only_presses()` 는 목록(POLICY)에 **적힌** 언론사만 돌려줬다. 그래서 누가 피드만 추가하고 POLICY 를 빠뜨리면, 그 언론사 본문이 LLM 으로 갔다. AI 활용 금지 언론사였다면 위반이 된다.

## 들어가고 나오는 것

| | 내용 |
|---|---|
| `write_json(path, data)` | 들어감: 파일 경로, 저장할 값. 나옴: 없음. 실패하면 `OSError` (이전 파일은 그대로) |
| `title_only_presses()` | 나옴: 본문·LLM 을 쓰지 않을 언론사 이름 목록 (POLICY + 자동 바꿈 + 피드 전부에서 고름) |
| 비용 | 0 |

## 코드 따라 읽기

**① 원자적 쓰기** (`core/util.py` `write_json`)
```python
tmp = path.with_name(f"{path.stem}.{os.getpid()}.{threading.get_ident()}.tmp")
tmp.write_text(json.dumps(data, ...))   # 1) 임시 파일에 끝까지 씀
tmp.replace(path)                        # 2) 이름 바꾸기 = 한 번에 바뀜
```
- `replace` 는 운영체제가 "옛 파일 아니면 새 파일" 둘 중 하나만 보이게 해 준다. 반쯤 쓴 상태는 보이지 않는다
- 임시 이름에 프로세스 번호(pid)와 스레드 번호를 넣는다. 그래야 동시에 써도 서로의 임시 파일을 덮지 않는다
- `finally: tmp.unlink(missing_ok=True)`: 실패해도 임시 파일이 남지 않게 지운다

쓰는 곳 4개: 차단기(`resilience.py`), 언론사 방침(`press_policy.py`), 알림 상태(`notify.py`), LLM 비용(`step5_summary.py`). 예전에는 LLM 비용만 이 방식이었는데, 이번에 한 함수로 모았다.

**② 목록에 없는 언론사** (`core/press_policy.py` `_known`)
```python
def _known():
    from hk_llm.steps.step1_rss import FEEDS   # 함수 안에서 import (아래 설명)
    return set(POLICY) | set(_load().get("override", {})) | set(FEEDS)
```
- `policy(press)` 는 POLICY 에 없으면 원래도 TITLE_ONLY 를 돌려줬다. 문제는 **후보 목록**에 그 언론사가 아예 없었던 것
- 함수 안에서 import 하는 이유: `step1_rss` 가 `press_policy` 를 import 한다. 파일 맨 위에서 서로 import 하면 순환 import 오류가 난다

**③ COMMON_NAMES 옮기기**: "대상·동서·고려" 처럼 일반 단어와 같은 종목명 목록이 `sns.py` 에 있었다. 그런데 `title_only.py` 가 이 목록을 가져다 썼다. 그러면 SNS 코드를 지울 때 제목만 연결도 같이 깨진다. 그래서 목록을 쓰는 곳 중 남을 쪽(`title_only.py`)으로 옮겼다.
