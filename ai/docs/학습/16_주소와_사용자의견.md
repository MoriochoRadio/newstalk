# 16. 주소로 화면 열기, 사용자 의견 받기, 판단 근거 공개 (2026-11-13)

## 한 줄 요약

화면 상태를 **주소(URL)** 에 적어 링크로 공유·뒤로 가기가 되게 하고, 사용자가 **"연결이 틀렸어요"** 를 알려 주면 DB 에 쌓아 품질 점검에 쓴다. 정확도와 한계는 **"판단 방법·정확도"** 창으로 공개한다.

## 왜 필요한가

- 예전에는 어떤 화면을 봐도 주소가 `localhost:5173/` 하나였다. 그래서 "삼성전자 화면 링크 보내 줘"가 안 되고, 뒤로 가기를 누르면 사이트를 나가 버렸다
- 정답지(99건)는 한 번 만들면 끝이라, 실제 사용 중에 생기는 틀린 연결은 알 길이 없었다. 쓰는 사람이 가장 먼저 본다
- 정확도를 재 놓고 화면에는 안 보여 줬다. 금융 정보는 "얼마나 믿어도 되는지"를 같이 알려야 한다

## 들어가고 나오는 것

| | 내용 |
|---|---|
| 주소 → 화면 | `readUrlState("?stock=005930&tab=news")` → `{ activeNav: 'stock', selectedStockCode: '005930', stockTab: 'news', … }` |
| 화면 → 주소 | `buildSearch(상태)` → `"?stock=005930&tab=news"` (홈이면 `""`) |
| 의견 | `POST /api/articles/17/stocks/000660/feedback {kind: "WRONG_STOCK"}` → 204, DB `link_feedback` 1줄 |
| 비용 | 0 (LLM 안 씀) |

## 코드 따라 읽기

**① 주소 읽기는 의심부터** (`frontend/src/hooks/urlState.js`)
```js
const STOCK_CODE = /^[0-9A-Z]{6}$/;
if (STOCK_CODE.test(stock)) { … }   // 모양이 맞을 때만
```
주소는 누구나 손으로 고칠 수 있다. `?stock=<script>` 같은 값은 버리고 기본 화면을 보여 준다.

**② 화면이 바뀌면 주소를 바꾼다** (`DashboardPageV7.jsx`)
```js
if (urlReady.current) window.history.pushState(null, '', url);  // 기록 한 칸 추가 → 뒤로 가기
else window.history.replaceState(null, '', url);                 // 처음 한 번은 바꿔치기만
```
뒤로 가기를 누르면 브라우저가 `popstate` 를 알려 주고, 그때 주소를 다시 읽어 화면을 맞춘다. 주소가 이미 같으므로 다시 기록하지 않아 무한 반복이 생기지 않는다.

**③ 같은 의견은 한 번만** (`V18__create_link_feedback.sql`, 11/19 합치며 V17 → V18, `LinkFeedbackMapper.xml`)
```sql
UNIQUE KEY uq_link_feedback (article_id, stock_code, user_id, kind)
INSERT IGNORE INTO link_feedback …
```
버튼을 열 번 눌러도 1줄. 그래서 "몇 명이 알렸나" = 줄 수가 된다. 로그인한 사람만 보낼 수 있게 해서 아무나 쌓지 못하게 했다.

**④ 의견은 정답이 아니다** (`ai/eval/feedback.py`)
여러 사람이 알린 연결부터 보여 주지만, 정답지·규칙에 넣기 전에 사람이 기사를 읽고 판단한다. 사용자도 틀릴 수 있기 때문이다.

## 직접 해보기

```
http://localhost:5173/?stock=000660&tab=news     # SK하이닉스 뉴스 탭이 바로 열림
python -m eval.feedback                           # (ai 폴더) 받은 의견 보기
```

## 확인 질문

1. 처음 화면을 열 때 `pushState` 대신 `replaceState` 를 쓰는 이유는?
<details><summary>▶ 답 보기</summary>처음 주소를 정리하는 것은 "화면 이동"이 아니다. pushState 를 쓰면 뒤로 가기를 눌렀을 때 같은 화면이 한 번 더 나와 두 번 눌러야 나가진다.</details>

2. 의견을 `article_stock` 줄에 붙이지 않고 (기사, 종목) 으로 따로 저장한 이유는?
<details><summary>▶ 답 보기</summary>AI 가 규칙을 바꿔 다시 연결하면 article_stock 줄을 지우고 새로 만든다. 거기 붙였다면 의견도 같이 사라진다. 따로 두면 "고친 뒤 그 연결이 없어졌나"를 확인할 수 있다.</details>
