## 2. NAVER API HUB 뉴스 검색

- 네이버 개발자센터가 아니라 **NAVER API HUB** (네이버 클라우드 플랫폼) 에서 신청. 결제수단 등록 필수
- 호출: `https://naverapihub.apigw.ntruss.com/search/v1/news`
  - 헤더 `X-NCP-APIGW-API-KEY-ID`, `X-NCP-APIGW-API-KEY` (옛 헤더 `X-Naver-Client-Id` 는 401)
- 요금: 검색 API 는 월 775,000건·**일 25,000건** 무료, 일 한도에서 막혀 과금 없음. 검색어 트렌드는 3만 건 초과분 유료 구간(현재 한시 무료)
- 응답 특징
  - 제목에 `<b>` 강조 태그, HTML 엔티티(`&quot;`), 중간 `...` 잘림
  - `pubDate` 는 `+0900` 포함 RFC 822 → KST 변환 쉬움
  - 원문 링크가 여러 언론사로 흩어짐 → 언론사마다 robots.txt 자동 확인 필요
- ❌ **날짜 지정 검색 불가**: `startDate`, `ds/de` 등 넣어도 무시됨
- ❌ **최신 1,000건까지만**: `start=1001` → 400 "부적절한 start 값"

## 7. 국내외 공공·오픈 출처 추가 조사 및 법적 한계 검토 (2026-11-12)

민간 언론사 RSS 외에 저작권·약관 제약을 줄일 수 있는 국내외 공공·오픈 출처와 각 출처의 법적·실무적 예외 사항을 함께 정리함. ("100% 무결점"이 아니라 각 제도의 적용 범위와 예외 조건을 기준으로 판단해야 함)

### 7-1. 국내 공공저작물·공공데이터 (`저작권법 제24조의2` · `data.go.kr`)

- **법적 근거와 예외:** `저작권법 제24조의2`(공공저작물의 자유이용)에 따라 국가·지자체가 업무상 작성해 공표한 저작물은 허락 없이 이용할 수 있으나, ① 국가안전보장 정보 ② 개인의 사생활·사업상 비밀 ③ 다른 법률에 따른 공개 제한 정보 ④ 한국저작권위원회에 등록된 국유저작물은 제외됨. 또한 보도자료 안에 포함된 **제3자 사진·이미지·인용문**은 자유이용 대상이 아님(텍스트만 사용).
- **`data.go.kr` 데이터셋별 확인 필요:** 공공데이터포털이라도 데이터셋마다 공공누리 유형(1~4유형)이 다르므로 개별 상세 페이지의 `이용허락범위`를 직접 확인해야 함 (예: 금융위·거래소 일부 시세 API는 공공누리 4유형으로 상업적 이용·변경 금지).

### 7-2. 해외 공공·오픈 출처 및 한계

- **미국 연방정부 저작물(`17 U.S.C. § 105`)의 속지주의 한계:** 미국 연방공무원이 직무상 작성한 저작물은 미국 내에서 저작권 보호를 받지 않으나(Public Domain), 입법 기록(`House Report No. 94-1476`)에 따르면 **"이 규정은 해외에서 해당 저작물의 보호에 영향을 주지 않는다"**고 명시되어 있음. 즉 미국 밖(한국 등)에서는 이론상 미국 정부가 저작권을 행사할 여지가 남아 있으므로(단, `CC0`를 별도 선언한 데이터는 전 세계 권리 포기) "전 세계 100% 퍼블릭 도메인"으로 단정하면 안 됨.
